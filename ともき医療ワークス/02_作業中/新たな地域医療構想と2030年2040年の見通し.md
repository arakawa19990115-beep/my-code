# 新たな地域医療構想と、2030年・2040年の見通し

作成日:2026年9月1日
対象:医療経営者向け提案の基礎資料(観点2)

---

## 1. 結論

**結論1:国が見ている年は2040年です。2030年は公式の目標年ではありません。**
新たな地域医療構想の目標年は2040年です。
ただし複数の推計で、2030年前後が「転換点」になります。
経営者には、この2つを分けて説明する必要があります。

**結論2:病院にとっての締切は2028年度です。2040年ではありません。**
2028年度までに、各医療機関が2040年に担う機能が協議で決まります。
急性期拠点を担う病院は、具体的な医療機関名まで決められます。
つまり、いま席を取る動きが必要です。

**結論3:「回復期」が「包括期」に変わります。ここが最大の実務変更です。**
高齢者救急の受け皿として、包括期機能が位置づけられました。
自院がどの機能で残るかを、2026年度から2027年度に決めることになります。

---

## 2. 新たな地域医療構想とは(事実)

### 何が変わるのか
現行の地域医療構想は、2025年を目標に病床数を調整する仕組みでした。
新たな構想は、対象と目標年の両方が広がります。

| 項目 | 現行 | 新たな構想 |
|---|---|---|
| 目標年 | 2025年 | 2040年 |
| 対象 | 入院(病床)中心 | 入院・外来・在宅・介護連携・人材確保 |
| 病床機能の区分 | 高度急性期・急性期・回復期・慢性期 | 高度急性期・急性期・**包括期**・慢性期 |
| 報告の仕組み | 病床機能報告 | 病床機能報告 + **医療機関機能報告**(新設) |

※ 現行の地域医療構想と病床機能報告のゴールは、2026年6月30日まで延長されました。

### 医療機関機能報告(新設)
病棟単位ではなく、病院単位で担う機能を報告する仕組みです。
報告する機能は、次のとおりです。

- 急性期拠点機能
- 高齢者救急・地域急性期機能
- 在宅医療等連携機能
- 専門等機能
- 医育及び広域診療機能

### 包括期機能とは
高齢者救急等を受け入れる機能です。次を包括的に提供します。
- 入院早期からの治療
- リハビリテーション・栄養・口腔管理の一体的な取組
- 早期の在宅復帰

**要点:「回復期」の名称変更ではありません。役割の定義が変わりました。**
高齢者救急を受ける前提の機能になっています。

## 3. 制度のスケジュール(事実)

| 時期 | 内容 |
|---|---|
| 2024年12月18日 | 「新たな地域医療構想に関するとりまとめ」公表(検討会) |
| 2025年度 | 国がガイドラインを検討・作成 |
| 2026年3月19日 | とりまとめ(地域医療構想及び医療計画等に関する検討会) |
| 2026年6月30日 | 現行の地域医療構想・病床機能報告のゴール(延長後) |
| 2026年7月3日 | 「地域医療構想策定ガイドライン」公表 |
| 2026年度 | 都道府県が医療提供体制の方向性・必要病床数の推計を検討 |
| **2027年4月1日** | **改正医療法に基づく新構想の取組が施行** |
| 2027年度〜2028年度 | 医療機関機能に着目した連携・再編・集約化の協議 |
| **2028年度まで** | **2040年に各医療機関が担う機能・必要病床数を策定** |

国は2026年度から2028年度を「集中的な検討期間」と位置づけています。

**経営上の意味:動く時期は、いまから2年半です。**
2028年度に決まったことが、2040年までの前提になります。

## 4. 2030年の見通し

### 前提の確認
2030年は、新構想の公式な目標年ではありません。
しかし、複数の推計で転換点として現れます。

### 転換点1:医師の需給が均衡します
- 医学部定員を現在の9,262人で継続した場合の推計です
- 中位推計:2024年頃に約30万人で均衡
- 上位推計:2033年頃に約32万人で均衡
- どちらの推計でも、2040年には約1.8万人程度が供給過剰になる見込みです

出典:厚生労働省 医療従事者の需給に関する検討会をもとにした二次情報

**読み方:2030年前後に「医師不足の時代」が終わります。**
ただし、これは全国の総数の話です。地域偏在と診療科偏在は別問題です。
愛知県は人口10万対224.4人で全国平均以下です。総数が均衡しても、県内は楽になりません。

### 転換点2:地域によって医療需要のピークが分かれます
- 全国の入院患者数のピークは2040年です
- しかし2020年までに、すでに90の医療圏がピークを越えました
- 医療需要のピークが2040年の地域(大都市)と、2010年だった地域(過疎地域)に分かれています

**読み方:2030年頃には、県内で「増える地域」と「減る地域」の差がはっきりします。**

### 2030年までに経営者がすべきこと(仮説)
1. 2028年度の協議で、自院の機能を確定させる
2. 医師の採用は、2030年前後までが売り手市場の想定で動く
3. 自院の商圏が「増える側」か「減る側」かを、市町村単位で確認する

## 5. 2040年の見通し

### 人口と需要
- 2025年から2040年にかけて、高齢者人口は都市部で大きく増加します
  - 東京都、神奈川県などが該当します
  - 一方、21の県では高齢者人口が減少します
- 入院需要は、都市部で2040年にかけて増加し、過疎地域では減少します
- 85歳以上は2040年に向けて増え続けます
- 医療と介護の両方を必要とする人が増えます

### 退院先の変化(全国推計)
65歳以上が2025年から2040年に増える医療圏(全国132圏域)では、次が見込まれます。
- 高齢の退院患者数:15%増加
- 介護施設への退院:34%増加
- 他の医療機関への退院:18%増加

**読み方:2040年の病院経営は、「出口」で決まります。**
介護施設と他医療機関への退院が、大きく増えます。
連携先を持たない病院は、在院日数が延びて稼働が悪化します。

### 人材
- 医師は2040年に約1.8万人の供給過剰になる見込みです(全国総数)
- 看護職員の需給推計は、都道府県ごとに2040年頃まで算定する方針です
- 推計期間を新構想に合わせる方向で検討が進んでいます

出典:厚生労働省「2040年に向けた看護職員の養成・確保の在り方に関する検討会」(2026年4月10日 第1回)

## 6. 2030年と2040年の対比(まとめ表)

| 論点 | 2030年頃 | 2040年 |
|---|---|---|
| 制度上の位置づけ | 公式の目標年ではない | 新構想の目標年 |
| 病院の意思決定 | 2028年度までに機能が確定済み | 決まった機能で運営している |
| 医師の需給 | 均衡に向かう(2024〜2033年頃) | 全国で約1.8万人の供給過剰 |
| 入院需要 | 地域差がはっきりする | 全国のピーク。都市は増、過疎は減 |
| 患者像 | 75歳以上の増加は鈍化 | 85歳以上が中心。医療と介護の複合 |
| 経営の勝負どころ | 機能の選択と席取り | 退院先の確保と連携網 |

## 7. 2つの視点からの検討

### 医療経営コンサルタントの視点
- 2028年度の協議が全てです。ここで機能が決まると、後から変えるのは困難です
- 急性期拠点は数が絞られます。名指しで決まる以上、取りに行くか降りるかの判断が要ります
- 包括期は、高齢者救急を受ける覚悟が必要です。名前だけ変えても務まりません
- 在宅医療等連携機能は、地域に必ず必要です。競合が少ない領域でもあります

### 事業コンサルタントの視点
- 医師が2040年に供給過剰になるなら、いまの採用競争は一時的です
- ただし2030年までは厳しいままです。この5年をどう乗り切るかが勝負です
- 退院先の確保は、連携ではなく「保有」も選択肢です。介護事業への進出を検討すべきです
- 2028年度で機能が固まると、その後の投資判断は逆に楽になります。不確実性が減ります

### 意見が食い違う点
**争点:急性期拠点を取りに行くべきか。**

- 医療経営側:取れる病院は取るべきです。地域の基幹として残れます
- 事業側:取ると設備投資と医師確保の負担が続きます。降りて包括期に集中する方が収益は安定します

**この検討での結論:**
自院の圏域の人口動態で判断を分けます。
- 需要が2040年まで増える圏域:急性期拠点を狙う価値があります
- 需要が既にピークを越えた圏域:包括期と在宅連携に集中します

理由は1つです。急性期は症例数が集まらないと質も収益も成立しないためです。

## 8. 愛知県への含意

前回の資料(愛知県の人口動態)と重ねると、次が言えます。

| 圏域タイプ | 2030年 | 2040年 | 狙う機能(案) |
|---|---|---|---|
| 名古屋 | 競合激化 | 需要増が続く見込み | 急性期拠点、専門等機能 |
| 西三河南部・尾張北部 | 人口規模を維持 | 高齢者増 | 急性期拠点または包括期 |
| 知多半島・海部 | 高齢化が進む | 包括期需要が中心 | 包括期、在宅医療等連携 |
| 東三河北部・尾張中部 | 需要が減少に転じる | 縮小 | 在宅医療等連携、慢性期 |

※ この表は整理案です。愛知県の圏域別推計は未確認です。

**愛知固有の注意点:**
高齢化率が全国3番目に低い県です。危機感が生まれにくい環境です。
一方で2028年度の締切は、他県と同じです。
「まだ余裕がある」という判断が、席取りの遅れにつながります。
