# ティール組織の考え方を医療経営に導入する

作成日:2026年9月1日
位置づけ:ともき医療ワークスの中核となる考え方(組織のあり方)

---

## 1. 結論

**結論1:全面導入はできません。「二層構造」なら導入できます。**
医療法により、管理者(院長)の監督責任は他者に移せません。
安全と法令の層は階層型を維持します。その上の層を現場に渡します。

**結論2:導入の理由は、理念ではなく人材確保です。**
「働きやすいから」では経営者は動きません。
離職率と欠勤率という数字で語る必要があります。

**結論3:前提はデータの透明化です。順序を逆にすると失敗します。**
判断材料がないまま権限だけ渡すと、現場は混乱します。
データドリブンの整備が先、権限委譲が後です。

---

## 2. なぜ今、管理型の限界が来ているのか

### 人手不足の現状(事実)
- 看護師・保健師・助産師の有効求人倍率:2.37倍
- 看護師全体の離職率:11.3%
- 医療・福祉業界全体の離職率:14.6%(令和5年)
- 看護師が辞めたい理由の約6割が「人手不足による仕事のきつさ」
- 2025年時点で最大約27万人の看護職員が不足するとの試算(厚生労働省)

出典:厚生労働省の試算、業界各社の集計をもとにした二次情報です。
※ 数値の集計年と対象範囲は資料によって異なります。要確認です。

### 悪循環の構造(仮説)
```
人手不足 → 1人あたりの負担増 → 離職
   ↑                              ↓
   ←──── さらに人手不足 ←────────
```
管理型のマネジメントは、この循環を止められません。
指示を出す人も、指示を受ける人も、すでに限界だからです。

### 医療ニーズの複雑化
- 高齢者は複数の疾患を同時に持ちます。単一の診療科では完結しません
- 在宅・介護・生活支援まで含めた対応が求められます
- 現場で起きることを、すべて上位者が事前に想定するのは不可能です

**要点:判断すべきことが増えすぎました。**
判断を上に集めると、そこが渋滞します。現場が止まります。

## 3. ティール組織とは何か

フレデリック・ラルーが提唱した組織モデルです。3つの要素があります。

| 要素 | 内容 | 医療での意味 |
|---|---|---|
| セルフマネジメント(自主経営) | 上司の指示なしにチームが決める | シフト・業務分担を病棟が決める |
| ホールネス(全体性) | 役割ではなく人として関わる | 職種の壁を越えて発言できる |
| 存在目的(進化する目的) | 組織の目的を全員で問い続ける | 何のための病院かを共有する |

補足:ティールとは青緑色のことです。組織の発達段階を色で表した中の最上段です。

## 4. 医療での先行事例:ビュートゾルフ(オランダ)

オランダの在宅ケア組織です。ティール組織の代表例として知られます。

### 仕組み
- 看護師は原則12名以下のチームに分かれます
- チームが地域を受け持ちます
- シフト管理、業績管理、地域連携、研修まで、チームが自分で行います
- 本部やマネージャーが担う役割を、現場が引き受けます
- 提供したケアの質や治療時間は、データで可視化されます

### 成果(報告されている数値)
- 病気を理由にした欠勤率:従来型と比べて60%低い
- 離職率:33%低い
- 2012年、患者満足度で国内1位の評価
- コストを削減しつつ、ケアの質を維持

出典:SELECK、We介護の記事(二次情報)
※ 調査主体と時点が明示されていません。提案に使う前に原典の確認が必要です。

### ここから学べること
データの可視化が、自主経営の前提になっています。
「自由にやってよい」ではありません。「事実が見えるから、自分で決められる」のです。
第1の考え方(データドリブン)と、完全につながっています。

## 5. 医療で「渡せない権限」がある(重要)

日本の医療機関には、法律上の制約があります。ここを無視した提案は通りません。

| 根拠 | 内容 |
|---|---|
| 医療法 第15条第1項 | 病院の管理者は、勤務する医師・歯科医師・薬剤師その他の従業者を監督し、管理運営に必要な注意をしなければならない |
| 医療法 第6条の12 | 管理者は、医療安全確保の指針策定、従業者への研修その他の措置を講じなければならない |

つまり、次の領域は階層型を維持する必要があります。

- 医療安全管理、院内感染対策
- 医薬品・医療機器・診療用放射線の安全管理
- 診療報酬の施設基準に関わる体制
- 最終的な診療責任と、有事の指揮命令

**ここを「フラットにしましょう」と提案してはいけません。**
法令違反になります。経営者の信頼も失います。

## 6. 提案する形:二層構造

```
┌─────────────────────────────────┐
│ 【階層型を維持する層】               │
│  医療安全・感染対策・法令遵守         │
│  最終的な診療責任・有事の指揮         │
│  → 管理者(院長)の責任は移さない      │
├─────────────────────────────────┤
│ 【自主経営に移す層】                 │
│  シフト編成・業務分担・勤務調整       │
│  業務改善・work flowの設計           │
│  チーム内の採用・教育・研修           │
│  日常のケア方針の判断                │
│  小額の備品購入・環境整備            │
│  → チームが決める。上長は承認しない   │
└─────────────────────────────────┘
```

### 領域ごとの導入可否(整理案)
| 領域 | 導入可否 | 理由 |
|---|---|---|
| シフト・勤務調整 | ◎ | 効果が大きく、法的制約がない |
| 業務改善・手順の見直し | ◎ | 現場が一番よく知っている |
| チーム内の教育・研修 | ○ | 安全研修は管理者責任と接続が必要 |
| 採用の面接・選考 | ○ | 最終決定は法人。一次は現場で可能 |
| 日常のケア方針 | ○ | 標準治療の枠内であれば可能 |
| 予算・投資の決定 | △ | 小額に限る。上限を明示する |
| 医療安全・感染対策 | × | 医療法上、管理者の責任 |
| 施設基準に関わる体制 | × | 届出と実態の一致が必要 |

※ この表は整理案です。個別の病院の実態で見直しが必要です。

## 7. 2つの視点からの検討

### 医療経営コンサルタントの視点
- 賛成です。ただし安全管理の層は絶対に触らせません
- シフトの自己編成は、離職防止に直接効きます。ここから始めるべきです
- 現場に渡すと、最初は必ず質が落ちます。3か月から6か月は覚悟が必要です
- 師長・主任の役割が変わります。この層のケアを怠ると、全体が壊れます

### 事業コンサルタントの視点
- 賛成です。人材確保はいま最大の投資テーマです
- 採用コストと離職コストで効果を測るべきです。感覚では評価できません
- 中間管理職の人件費が浮くわけではありません。役割の転換であり、削減ではありません
- 一度渡した権限を戻すと、信頼は二度と戻りません。始める前に覚悟を決めるべきです

### 意見が食い違う点
**争点:どこから始めるか。**

- 医療経営側:病棟単位のシフト自己編成から。効果が見えやすく、リスクが小さい
- 事業側:存在目的の共有から。土台がないまま権限を渡すと形だけになる

**この検討での結論:**
シフトの自己編成から始めます。理由は3つです。
1. 離職率という数字で効果を測れます
2. 法的なリスクがありません
3. 成功体験があると、次の領域に進みやすくなります

存在目的の共有は同時に進めます。ただし、それを条件にはしません。
理念から入ると、忙しい現場では「また上の思いつきか」と受け取られます。

## 8. 導入のステップ(仮説)

| 段階 | やること | ねらい |
|---|---|---|
| 準備 | 現在の離職率・欠勤率・残業時間を計測する | 効果測定の基準を作る |
| 準備 | データの可視化を先に整える | 判断材料を現場に渡す |
| 第1段階 | 1病棟で、シフトの自己編成を試す | 小さく試す |
| 第2段階 | 業務改善の権限を同じ病棟に渡す | 範囲を広げる |
| 第3段階 | 師長・主任の役割を再定義する | 支援者に転換する |
| 第4段階 | 他病棟へ展開する | 横に広げる |
| 継続 | 四半期ごとに離職率と質の指標を確認する | 両立を確認する |

※ この表は仮説です。実績データに基づくものではありません。

## 9. 失敗するパターン

- 理念だけを語り、権限を渡さない → 「言葉だけ」と見なされます
- データを整えずに権限を渡す → 判断できず、現場が疲弊します
- 安全管理まで現場に投げる → 法令違反です。事故時に責任が問えません
- 中間管理職を放置する → 存在意義を失い、抵抗勢力になります
- うまくいかないと権限を戻す → 信頼が失われ、二度目はできません
- 全病棟で一斉に始める → 失敗したとき、比較対象がありません

## 10. 経営者に伝えるときの言い方(案)

「階層をなくす話ではありません。判断する場所を、現場に近づける話です」

「安全と法令の責任は、院長が持ち続けます。そこは変えません」

「目的は働きやすさではありません。人が辞めない病院にすることです」

## 11. 前の2つの文書とのつながり

- **データドリブン(第1の考え方)**:自主経営の前提です。事実が見えないと決められません
- **2026年度改定**:賃上げ財源が入りました。人材への投資を語る根拠になります
- 改定で入院基本料が上がりました。増収は病床稼働率に依存します
- 稼働率は人員配置に依存します。つまり離職防止は、直接収益に効きます
