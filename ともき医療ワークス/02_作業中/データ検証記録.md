## 3. 訂正が必要な数値(5件)

### 訂正1:看護職員の離職率 11.3% → 11.0%【重要】

| | 誤 | 正 |
|---|---|---|
| 正規雇用看護職員の離職率 | 11.3% | **11.0%** |
| 対象年度 | 記載なし | **2024年度** |

- 11.3%は**2023年度**の数値でした
- 最新は2024年度で11.0%です。0.3ポイント低下しました
- 新卒採用者8.4%(0.4ポイント減)、既卒採用者16.1%
- 出典:日本看護協会「2025年病院看護実態調査」(2026年3月31日公表)

**講演への影響:**
「離職率が高い」という主張はやや弱まります。実際には低下傾向です。
ただし人手不足の深刻さは、求人倍率と現場の声の方で語るべきです。

### 訂正2:医師需給推計は2016年公表【最重要】

| | 誤解を招く記載 | 正しい記載 |
|---|---|---|
| 「2033年頃に均衡」 | 現在の見通しのように読める | **2016年3月31日公表の推計** |
| 「2040年に約1.8万人の供給過剰」 | 同上 | 同上 |

- この推計は、厚生労働省 医師需給分科会が**2016年3月31日**に示したものです
- 医学部定員9,262人を継続した場合の前提です
- 10年前の推計を、2026年の講演で現在の見通しとして語るのは危険です

**講演への影響:**
「2030年頃に医師不足の時代が終わる」という主張は、根拠が弱くなります。
講演では「2016年時点の推計では」と明示するか、この論点を落とすべきです。

### 訂正3:人口10万対医師数の全国比較が古い年次

| | 誤 | 正 |
|---|---|---|
| 最上位 | 徳島県 304.0人 | **徳島県 345.4人**(令和6年) |
| 最下位 | 記載なし | **埼玉県 189.1人**(令和6年) |
| 愛知県 224.4人 | 年次の記載なし | **令和4年(2022年)のデータ** |

- 愛知の224.4人は「愛知県医師確保計画(2024-2026)」に基づく令和4年の数値です
- 全国比較に使った数字は、より古い年次のものでした
- **令和6年(2024年)医師・歯科医師・薬剤師統計の概況が2025年12月23日に公表済み**です
- 愛知県の令和6年の値は、この環境では確認できませんでした

**講演への影響:**
「愛知は全国平均以下」という主張は変わらない見込みです。
ただし年次をそろえる必要があります。全国上位の比較は、講演から外すのが安全です。

### 訂正4:ビュートゾルフの数値は原典が特定できず

| 日本語記事の記載 | 英語圏の資料(KPMG 2015等) |
|---|---|
| 欠勤率が60%低い | 欠勤率は「業界平均の約半分」 |
| 離職率が33%低い | 離職率10%(全国平均15%) → **33%低いと一致** |
| ― | 間接費8%(業界平均25%) |

- **33%は整合します。** 10%と15%の差は、ちょうど33%低い計算です
- **60%は幅があります。** 「約半分」との記述で、60%と断定する根拠は見つかりませんでした
- 原典は、フレデリック・ラルー『ティール組織』(2014年)とKPMG(2015年)の調査と考えられます

**講演への影響:**
33%はそのまま使えます。60%は「業界平均の約半分」と言い換えるのが安全です。

**講演で使うなら▲0.87%です。**改定率の話をしているためです。
