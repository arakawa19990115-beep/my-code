# ビュートゾルフの自主経営は、日本の医療現場に導入できるか

- 検証の枠組み:CTI コーアクティブの理念 × ティール組織の要諦
- 作成日:2026年9月1日
- 想定読者:病院経営層、看護管理者(部長・師長)

---

## 1. 結論

**結論1:3つは別々の考え方ではありません。同じ人間観を共有しています。**
接続点はただ1つ。「相手は既に答えを持っている」という前提です。
ビュートゾルフは、この人間観を組織の仕組みに実装したものです。

**結論2:全面導入はできません。しかし「師長のコーチ化」なら明日できます。**
法の壁があるのは、安全管理と最終責任の層だけです。
話し方を変えることに、許可も予算も要りません。

**結論3:訪問看護ステーションは、ほぼそのまま導入できます。**
ビュートゾルフと業態が同じです。病棟より先に、ここから試すべきです。

## 2. ビュートゾルフのオペレーション(事実)

| 項目 | 内容 |
|---|---|
| 設立 | 2006年(オランダ) |
| 規模 | 看護師 約1万5,000人 / 約1,000の自主経営チーム |
| チーム単位 | 最大12名。1チームで40〜60人の利用者を担当 |
| **管理職** | **ゼロ人** |
| コーチ | 約15人 |
| バックオフィス | 約40人 |

### チームが自分で決めること
- 利用者のケアプランの作成
- スタッフの採用と教育
- シフトと勤務の調整
- 予算の管理
- 地域の開業医との連携
- 事務所の賃借

### コーチの決定的な特徴
> コーチはチームの上司ではありません。
> チームに対して何かを命令したり、意思決定したりする権限は、一切持っていません。
> 役割は、チームが問題に直面したときに相談に乗り、話し合いが円滑に進むよう手助けすることです。

**ここが全ての鍵です。**
1万5,000人を、15人のコーチが支えています。比率は1対1,000です。
それでも回るのは、コーチが「決めない」からです。決めていたら、渋滞します。

出典:嘉村賢州「オランダで急成長を遂げるティール組織、Buurtzorgの驚きの組織運営」ほか
※ 人数は資料により幅があります(コーチ15人〜50人、看護師1万人〜1万5,000人)。要原典確認。

## 3. CTI コーアクティブ・コーチングの理念(事実)

CTI(現 Co-Active Training Institute)が提唱する枠組みです。

### 4つの礎
| | 礎 | 内容 |
|---|---|---|
| 1 | **人はもともと創造力と才知にあふれ、欠けるところのない存在である** | 英語の頭文字でNCRW(Naturally Creative, Resourceful and Whole) |
| 2 | その人すべてに焦点を当てる | 役割ではなく、人として向き合う |
| 3 | 今この瞬間から創る | 計画通りではなく、いま起きていることを扱う |
| 4 | 本質的な変化を呼び起こす | 対処ではなく、根本の変化を起こす |

### 5つの資質
傾聴 / 直感 / 好奇心 / 行動と学習 / 自己管理

### 傾聴の3つのレベル
| レベル | 意識の向き先 |
|---|---|
| レベル1 内的傾聴 | 自分に向いている。相手の話が自分にとって何を意味するかを考えている |
| レベル2 集中的傾聴 | 相手に向いている |
| レベル3 全体的傾聴 | 場全体に向いている |

出典:CTIジャパン、『コーチング・バイブル』(第4版)

## 4. ティール組織の要諦(事実)

フレデリック・ラルーが提示した3つの要素です。

1. **セルフマネジメント(自主経営)**:上司の指示なしにチームが決める
2. **ホールネス(全体性)**:役割ではなく、人として関わる
3. **存在目的**:組織の目的を全員で問い続ける

---

## 5. 検証:3つは何を共有しているか【中核】

3つを並べると、同じ構造が見えます。

| | コーアクティブ | ティール組織 | ビュートゾルフ |
|---|---|---|---|
| 人間観 | 人は欠けるところのない存在(NCRW) | 人は信頼できる存在 | 看護師は自分で決められる |
| 役割の見方 | その人すべてに焦点を当てる | ホールネス(全体性) | 職種の枠を越えて担う |
| 決め方 | 答えは相手の中にある | セルフマネジメント | チームが全て決める |
| 支援者 | コーチは答えを与えない | 管理職を置かない | コーチに決定権はない |
| 目的 | 本質的な変化を呼び起こす | 存在目的を問い続ける | 「この人の自立を助ける」 |

### 導かれる命題
**ビュートゾルフの自主経営は、コーアクティブの人間観を、
組織のオペレーションに実装したものと言えます。**

理由は3つです。
1. コーチが命令も意思決定もしない。これは礎①NCRWそのものです
2. コーチの仕事は「相談に乗る」「話し合いを助ける」。傾聴と好奇心の実践です
3. 答えを持つのはチームである、という前提が共通しています

### 逆に言えば
**人間観を変えずに仕組みだけ真似ると、必ず失敗します。**
「チームで決めてください」と言いながら、上司が答えを持っていれば、
現場はその答えを当てにいきます。自主経営は成立しません。

## 6. 医療現場に導入できるか:領域別の検証

### 導入できない領域(法の壁)
医療法により、次は管理者(院長)の責任です。移せません。
- 医療法 第15条第1項:管理者は従業者を監督し、管理運営に必要な注意をする義務
- 医療法 第6条の12:管理者は医療安全確保の措置を講じる義務

したがって、**医療安全・感染対策・施設基準・最終的な診療責任・有事の指揮**は、階層型を維持します。

### 領域別の適用可能性(検証結果)

| 領域 | 可否 | 理由 |
|---|---|---|
| **訪問看護ステーション** | ◎ ほぼそのまま | ビュートゾルフと業態が同じ。チーム規模も近い |
| 病棟のシフト・勤務調整 | ◎ | 法的制約がなく、離職防止に直結する |
| 病棟の業務改善・手順 | ◎ | 現場が最もよく知っている |
| チーム内の教育・研修 | ○ | 安全研修は管理者責任と接続が必要 |
| 採用の一次面接 | ○ | 最終決定は法人。一次は現場で可能 |
| 日常のケア方針 | ○ | 標準治療の枠内なら可能 |
| 外来の運営 | △ | 医師の診療体制と一体のため、単独では動かしにくい |
| 予算・投資 | △ | 小額に限る。上限を明示する |
| 手術室・救急の指揮 | × | 有事の指揮命令系統を崩せない |
| 医療安全・感染対策 | × | 医療法上、管理者の責任 |

### 日本固有の壁(正直に)
1. **看護配置基準があります。** シフトの自由度は、施設基準の範囲内に限られます
2. **診療報酬に紐づく体制要件があります。** 届出と実態の一致が必要です
3. **多職種の階層が強い。** 看護部内で完結する領域から始めるのが現実的です
4. **日本での病院導入事例を、今回は見つけられませんでした**

## 7. 最小の一歩:師長を「コーチ」に変える

### なぜここから始めるのか
理由は3つです。
1. **許可も予算も要りません。** 話し方を変えるだけです
2. **師長が一番疲れています。** 板挟みの層です。ここが楽になると全体が変わります
3. **失敗しても損失がありません。** 元に戻すこともできます

### 具体的な言い換え(明日からできる)
| いままで | これから |
|---|---|
| 「この手順でやってください」 | 「どうするのが一番いいと思いますか」 |
| 「私が確認してから進めて」 | 「チームで決めて、決めたら教えてください」 |
| 「それは無理だと思う」 | 「やるとしたら、何が必要ですか」 |
| 「なぜできなかったのですか」 | 「次はどうすればうまくいきそうですか」 |
| (沈黙を埋める) | (3秒待つ) |

### 傾聴のレベルを上げる
会議中、自分の意識がどこに向いているかを確認します。
- 「次に何を言おうか」と考えている → レベル1です
- 相手の言葉に集中している → レベル2です
- 場の空気、言われていないことにも気づいている → レベル3です

**レベル1に気づくだけで、聞き方が変わります。**

---

## 8. やってはいけないこと

- 人間観を変えずに、仕組みだけ真似る(最大の失敗要因)
- 「自由にやっていい」と言いながら、上司が答えを持っている
- 医療安全まで現場に投げる(法令違反です)
- コーチ役が結論を言ってしまう(その瞬間、自主経営は終わります)
- うまくいかないと権限を戻す(信頼は二度と戻りません)
- 全部署で一斉に始める(比較対象がなくなります)

## 9. 90日の試し方(提案)

| 期間 | やること |
|---|---|
| 事前 | 離職率・欠勤率・残業時間・超過勤務を測る。基準を作る |
| 1〜30日 | 1つの病棟(または訪問看護)で、師長が5つの言い換えだけを実行する |
| 31〜60日 | シフトの自己編成を、その単位に渡す。師長は承認しない |
| 61〜90日 | 業務改善の権限を渡す。コーチ役として相談だけ受ける |
| 90日後 | 数字で確認する。質の指標も同時に見る |

**チームの人数は12名以下にしてください。**
ビュートゾルフが12名を上限にしている理由は、全員が発言できる規模だからです。

## 10. 期待できること・できないこと(正直に)

### 期待できること
- 師長の負担が減ります(承認業務がなくなるため)
- 現場の当事者意識が上がります
- 離職の理由が「人間関係」である場合、効果が見込めます

### 期待できないこと
- 人手不足そのものは解決しません
- 最初の1〜2か月は、むしろ混乱します
- 全ての人が自主性を歓迎するわけではありません。指示を求める人もいます
- 数字の改善は、早くても3か月後です

**仮説:最初の3か月は指標が悪化します。そこで止めると全て無駄になります。**
